# Adaptive Grilling

Use this Skill only as a questioning method. The Workflow and current Action own routing, waits, budgets, completion, and artifact custody.

Before asking, separate facts that can be derived from admitted repository evidence from intent or preference that only the user can supply. Investigate derivable facts first. Then ask exactly one question: choose the unresolved answer with the greatest effect on scope, responsibility, quality target, acceptance, or architecture. State the relevant context and trade-off plainly; do not hide several decisions inside one question.

After each answer, update the working understanding, expose any contradiction with frozen authority, and select the next highest-impact gap. Exercise the main scenario plus meaningful boundary, failure, recovery, and lifecycle cases. Treat suggested solutions as hypotheses until their required outcome and constraints are understood.

Closure requires a decision-oriented summary, explicit scope and non-goals, actors and scenarios, contextual quality expectations, acceptance evidence, known unknowns, and ownership. Never infer confirmation from silence or exploratory discussion. Return only the result shape admitted by the current Action.
