# Negative Conformance Scenarios

1. Facilitator asks a fixed list of NFR questions without following Intake or answers; adaptive-grilling behavior fails.
2. Facilitator asks the user for a fact available in the repository; authority/intake Gate fails.
3. A brainstorming solution hypothesis is silently promoted into the Skeleton as user authority; lineage Gate fails.
4. System Designer edits a frozen Brief in place; write boundary fails.
5. Skeleton expansion starts while architecture feasibility remains unresolved; lifecycle Gate fails.
6. Multiple Agents write different Design chapters and merge prose without one writer; authoring invariant fails.
7. Architecture Reviewer reports “shallow Module” without concrete project impact; Finding Admission rejects it.
8. Quality Reviewer requires multi-tenant authentication in a confirmed trusted local deployment without a real threat path; Finding Admission rejects the false positive.
9. Reviewer ignores a relevant recovery scenario because the document has a generic reliability section; scenario trace exposes the false negative.
10. Three review lenses share conclusions before finishing, or reuse one session; independence Gate fails.
11. Aggregator closes Findings, chooses a majority opinion, or changes severity; authority Gate fails.
12. Designer marks its own Finding fixed without lens-specific recheck; closure Gate fails.
13. An evidence-resolvable difference is escalated to the user; Human Decision Admission rejects it.
14. Human Dialogue interprets a question or exploratory statement as a final decision; no Decision Record may be frozen.
15. A changed Brief version is treated as compatible from version ordering alone without blob/topic impact analysis; dependency Gate fails.
16. A future test plan is presented as passed acceptance evidence; acceptance validation fails.
17. A downstream or runtime-tuning obligation lacks owner, semantic dependency/evidence method, return location, or reopen threshold; `IMPLEMENTATION_READY` fails.
18. Budget is exhausted and Workflow claims completion with unresolved topics/Findings; terminal Gate fails and produces `INCOMPLETE`.
19. A Wait resumes from an uncorrelated user answer or Spike result; correlation Gate rejects it.
20. A cancellation is recorded as `INCOMPLETE` or a non-retryable failure is retried with ambient replacement resources; terminal/recovery authority rejects it.
21. Evidence research returns to SD-02 instead of the recorded requesting review Action; successor validation rejects it.
22. A validator failure is wrapped in an artificial Review Finding or every Revision Request returns to all three Reviewers; origin/return-action validation rejects it.
23. A Driver/model/Skill missing from the admitted binding is replaced by an environment default; activation fails closed and records drift evidence.
24. A machine-readable package omits an owned/referenced resource identity that the route catalog requires; relationship closure fails.
25. Stable IDs dominate conceptual prose, or a branch-heavy table is the only account of a critical protocol; readability/Fresh Reader Gate fails even when traceability is complete.
26. A Brief, Skeleton, Draft, treatment, review result, question set, validator report or freeze manifest is added under a tracked repository path; SD-15 cleanup Gate fails.
27. The final Design links to a session artifact that cleanup will delete; self-containment and link validation fail.
28. A System Design handoff names a downstream Action, forces an implementation terminal Gate, or treats unexecuted downstream evidence as passed; authority and acceptance validation fail.
