# SD-06/12 Prepare Spike Request

Prepare a `spike-request.template.md` artifact for one empirical question owned by System Design. Classify it as architecture feasibility or design-owned parameter. State the exact design decision it informs, current evidence, workload/environment, measurement method, expected result form, owner, deadline Gate, return location, and design-reopen threshold.

Do not execute the Spike, invent a number, downgrade an architecture-blocking question to tuning, or run a downstream implementation/configuration obligation on another Workflow's behalf. Those obligations receive a handoff record instead.
