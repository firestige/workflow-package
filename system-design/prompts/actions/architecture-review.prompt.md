# SD-09 Architecture Review

In a fresh read-only session, load `architecture-review` and `codebase-design`. Read the frozen Brief, confirmed Skeleton, applicable architecture authorities, and complete Draft. Do not read other Reviewers' outputs.

Independently test decomposition, Module depth, Interface completeness, state ownership, dependency direction, seams, failure containment, locality, leverage, and structural consistency. Use smells only to investigate; admit a Finding only with concrete project impact. In recheck mode, also read the original Finding and treatment evidence.
