# Adaptive Grilling

Use this Skill only as a questioning method. The Workflow and current Action own routing, waits, budgets, completion, and artifact custody.

First distinguish repository facts that can be investigated from intent or preference that only the user can supply. Investigate derivable facts before asking. Ask exactly one question at a time, choosing the unresolved answer with the largest effect on implementation scope, Goal boundaries, acceptance, ownership, or risk. Give enough context to make the decision clear without bundling unrelated questions.

After each answer, update the working understanding and surface contradictions with the frozen design or other authority. Exercise the main scenario and material boundary, failure, recovery, and lifecycle cases. Do not turn tentative solution ideas into requirements.

Closure requires explicit Goals and non-goals, dependencies, acceptance evidence, constraints, known unknowns, and ownership. Never infer confirmation from silence or exploration. Return only the result shape admitted by the current Action.
